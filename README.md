# Mihika Patro: Personal Portfolio

Live site: https://mihikamadnpatro-ops.github.io/portfolio/

A single-page personal portfolio built for the Personal Portfolio Website assignment. It is written in plain HTML, CSS and vanilla JavaScript (no frameworks, no website builders).

## About the site
I'm a Data Science undergraduate at NMIMS, MPSTME Mumbai. The site covers:
- **About**: who I am, what I study and my technical skills
- **Projects**: ReviewLens (RAG app), RoomStyle AI, Loan Default Prediction, Cancer Death Rate Prediction
- **Design**: my committee work (Analytika, MPSTME Alumni Association, Social Conclave) and selected designs
- **Journey**: leadership, research (BARC NSRP) and community service at TISS
- **Certifications**: what I learnt from each
- **Contact**: email and GitHub, plus a downloadable resume

## Features
Dark neo-brutalist theme with violet and cyan accents, typewriter hero text, scroll-reveal animations (Intersection Observer), 3D-tilt project cards, magnetic buttons, a mobile slide-in menu, a contact form with floating labels, and a responsive layout for phone, tablet and laptop.

## Files
- `index.html`: the whole site (HTML, CSS and JS in one file)
